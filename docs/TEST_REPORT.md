# 테스트 결과

이 문서는 이 커밋 시점에 실제로 실행한 결과만 기록한다. 실행하지 않은 항목은 "미검증"이다.

## 1. 실행 환경

| 항목       | 값                                                       |
| ---------- | -------------------------------------------------------- |
| OS         | Linux 6.18 (컨테이너, root 실행)                         |
| Node.js    | 22.22.0 (테스트 러너), Electron 44.9.1 (번들 Node 24.22) |
| FFmpeg     | 6.1.1 (Ubuntu 빌드, libx264·libx265 포함, libvmaf 없음)  |

| 디스플레이 | Xvfb (xvfb-run)                                          |
| Windows    | 미사용. Windows 11 실행 검증은 하지 않았다               |

E2E 는 파일 선택 대화상자만 메인 프로세스에서 스텁으로 바꾼다. 나머지는 실제 UI 조작이다.
테스트 실행마다 격리된 사용자 데이터 디렉터리를 쓴다. 이전 실행의 기록이 섞이면 테스트가 깨진다.

E2E 는 root 로 실행되는 컨테이너이므로 Electron 에 `--no-sandbox` 를 넘겼다. 이것은 테스트 환경에만 적용되며,
앱 자체의 `sandbox: true` 설정은 그대로다.

## 6. 픽스처

모든 입력 영상은 `tests/fixtures/generate.ts` 가 FFmpeg 로 실행 시점에 만든다. 저장소에는 바이너리를 두지 않는다.

| 픽스처                               | 목적                                                                                        |
| ------------------------------------ | ------------------------------------------------------------------------------------------- |
| `h264_sdr.mp4`                       | 기본 H.264 SDR                                                                              |
| `no_audio.mp4`                       | 오디오 없음                                                                                 |
| `multi_audio.mkv`                    | 음성 2개(한국어, 영어), AC-3 포함                                                           |
| `subtitle.mkv`                       | SRT 자막                                                                                    |
| `rotated.mp4`                        | 표시 행렬 회전 90° (ffprobe 로 확인)                                                        |
| `vfr.mkv`                            | 프레임 일부를 규칙적으로 제거한 불규칙 타임스탬프 (VFR 유사, 평균 프레임레이트는 같게 나옴) |
| `hevc_10bit.mkv`                     | 10비트 H.265                                                                                |
| `hdr_like.mkv`                       | PQ 전달 특성 태그를 가진 10비트 영상 (실제 HDR 콘텐츠가 아니라 태그 검증용)                 |
| `corrupt.mp4`                        | 손상 입력 (임의 바이트)                                                                     |
| `한글 경로 폴더/테스트 영상 (1).mp4` | 한글·공백·괄호가 있는 경로                                                                  |

합성 영상의 절감률은 일반 영상의 성능 근거로 쓰지 않는다. 이 문서의 숫자는 기능 검증용이다.
