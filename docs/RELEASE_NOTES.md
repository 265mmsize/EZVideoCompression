# 릴리스 노트

## 1.9.0 (2026-11-01)

킹플레이어, 킹뷰, 킹컷의 공식 도움말과 스크린샷을 기준으로 적용할 수 있는 기능을 정리해 넣었다. 적용하지 못한 기능은 아래 제한에 적었다.

### 킹플레이어 (라이브러리 영상)

- **자막 자동 로드**: 같은 이름의 .srt, .vtt, .ass, .ssa 파일을 함께 읽어 화면에 띄운다. UTF-8, UTF-16, CP949 인코딩을 판정한다. 자막 파일은 읽기만 한다.
- **자막 싱크와 바꾸기**: `,` `.` 키로 0.5초씩 늦추거나 당기고, `/` 로 원래대로 한다. `J` 와 `Shift+J` 로 자막 파일을 바꾼다.
- **화면 확대와 이동**: `+` `-` 키 또는 버튼으로 확대하고, 확대한 상태에서 끌어서 옮긴다. `0` 키로 원래 크기로 돌아간다.
- **스크린샷**: `Ctrl+P` 또는 버튼으로 지금 장면을 원본 해상도 PNG로 저장한다. 같은 폴더에 "-frame-시간s" 이름으로 저장된다.
- **책갈피**: `B` 로 현재 위치를 저장하고, `Shift+PgUp/PgDn` 으로 이전·다음 책갈피로 이동한다. 목록에서 눌러 이동하거나 지울 수 있다. 이 PC의 브라우저 저장소에만 남는다.
- **볼륨과 음소거**: `↑` `↓` 로 5%씩 조절하고, `M` 으로 음소거한다.
- **회전 추가**: `Q` 로 반대 방향 90도 회전한다. `R` 과 `E` 는 시계 방향 90도다.
- **이전·다음 항목**: `PgUp/PgDn` 으로 목록에서 앞뒤 항목을 연다. `Home` 은 영상 처음으로 이동한다.
- **Ctrl+←/→**: 한 프레임 이동한다. 자막 싱크와 겹치지 않도록 쉼표와 마침표는 싱크로 바꿨다.

### 킹컷 (구간 저장)

- **스마트 컷**: 시작 지점부터 다음 키프레임까지만 재인코딩하고, 나머지는 무손실로 복사한다. 검증에 실패하면 정확 모드로 대체하고 그 사실을 알려 준다.
- **구간 목록 합치기**: 구간을 여러 개 모아 순서대로 한 파일로 저장한다. 최대 20개다.
- 구간 저장 방식은 빠름, 스마트, 정확 세 가지다.

### 킹뷰 (이미지)

- **컬러 피커**: `I` 키 또는 버튼으로 켠 뒤 이미지를 클릭하면 그 픽셀을 원본 해상도로 읽는다. HEX, RGB, HSL, HSV 값을 보여 주고 HEX를 복사할 수 있다. 미리보기 캔버스는 읽을 수 없어서 FFmpeg로 한 픽셀만 꺼낸다.
- **확대와 이동**: 휠로 커서 위치 기준 확대, 확대 상태에서 끌어 이동, 더블클릭으로 맞춤.
- **이전·다음 이미지**: `←` `→` 또는 `PgUp/PgDn` 으로 목록의 앞뒤 이미지를 연다.
- **별점 후 넘김**: `Alt+1`~`Alt+5` 로 별점을 매기고 다음 항목으로 넘어간다.

### 제한

- 킹뷰의 웹툰 모드, 2장 보기, 재생목록과 슬라이드쇼, 뷰어·탐색기 모드 전환, 압축 파일 안 이미지 보기, GIF 애니메이션 재생, EXIF와 GPS 편집, 루페(누르는 동안 확대), 영역 선택 후 검색은 아직 없다.
- 무손실 JPEG 자르기, OCR 글자 추출, RAW와 HDR 이미지는 이 빌드의 도구로 처리할 수 없다.
- 자막은 글자 내용만 표시한다. ASS 스타일과 SMI 형식, 자막 폰트와 위치 설정은 없다. 자동 자막 생성(Whisper)과 번역은 외부 모델이 필요해 넣지 않았다.
- 킹플레이어의 항상 위, PIP 모드, 창 크기 1~6 전환, URL 스트리밍과 유튜브 재생은 넣지 않았다. 외부 전송 없음 원칙과 맞지 않는다.
- 자동 업데이트, 파일 연결, 설정 화면의 캐시 항목은 앱 설정에 없다.

## 1.8.0 (2026-11-01)

영상 편집기에 시간 간격 나누기를, 라이브러리에 음성(.mp3) 추출을 추가했다. 킹플레이어·킹뷰 도움말과 스크린샷을 읽고 대조표를 갱신했다.

### 추가된 것

- **영상 편집기 간격으로 나누기**: 선택한 클립을 지정한 간격(초)으로 나눈다. 마지막 조각이 너무 짧으면 앞 조각에 붙이고, 조각은 최대 50개다. 같은 길이 나누기와 같은 규칙을 쓴다.
- **라이브러리 음성(.mp3) 추출**: 음성 트랙이 있는 영상에서 음성만 MP3로 저장한다. 같은 폴더에 "-audio.mp3"로 저장되며 원본은 바뀌지 않는다. 길이를 원본과 대조해 검증한다.

### 제한

- 킹컷의 스마트 컷, 여러 구간을 한 파일로 합치는 라이브러리 기능, 예상 크기 표시, 챕터 파일 저장은 아직 없다.
- 킹뷰의 웹툰 모드, 재생목록, 슬라이드쇼, 컬러 피커, OCR, 압축 파일 안 이미지 보기도 아직 없다. 대조표는 `docs/IMPLEMENTATION_STATUS.md` 에 있다.

## 1.6.0 (2026-11-01)

킹플레이어·킹컷·킹뷰 공식 페이지(kingtools.kr)를 읽고 앱과 대조해, 구현할 수 있는 항목을 추가했다. 대조 결과 전체는 `docs/IMPLEMENTATION_STATUS.md` 의 "킹툴즈 제품군 대조" 절에 있다.

### 추가된 것

- **라이브러리 영상 구간 저장**: A·B 구간을 새 파일로 저장한다. 두 방식이 있다.
  - 빠름: 재인코딩 없이 스트림을 복사한다. 화질은 그대로지만 시작은 앞쪽 키프레임에 맞춰져 결과가 조금 길 수 있다. 결과 길이를 알려 준다.
  - 정확: 재인코딩해 요청한 시점에 정확히 자른다 (H.264 CRF 18, AAC). 화질이 약간 바뀌고 시간이 더 걸린다.
  - 원본은 바뀌지 않고 같은 폴더에 "-cut" 이름으로 저장된다. 이름이 겹치면 번호를 붙이며, 결과는 라이브러리에 바로 반영된다.
- **플레이어 키보드 조작**: Space(재생·정지), ←/→(3초, Shift로 10초), , .(프레임 이동), Z(배속 초기화), X/C(감속·가속), [ ](A/B 지점), L(구간 반복), R(회전), H/V(반전). 영상 영역을 클릭한 뒤 쓴다.
- **영상 편집기 같은 길이로 나누기**: 선택한 클립을 2~10 조각으로 같은 길이 나눈다.
- **영상 편집기 유튜브 챕터**: 클립마다 "0:00 파일명" 형식의 챕터 목록을 만들고 복사한다. 시작 시간은 전환이 겹친 뒤의 타임라인 기준이다.
- **영상 편집기 오디오 제외**: 내보내기를 영상만으로 만든다.

### 제한

- 구간 저장 빠름 모드는 프레임 단위 정확도가 아니다 (킹컷의 스마트 컷은 아직 없다).
- 자막 표시, 재생목록, 책갈피, 스크린샷, 컬러 피커, EXIF·GPS 편집, OCR, 슬라이드쇼, 웹툰 모드, RAW 와 HDR 이미지는 이번 빌드에 없다. 대조표에 목록이 있다.
- 스트리밍과 유튜브 재생은 앱의 "외부 전송 없음" 원칙과 맞지 않아 넣지 않는다.

## 1.5.0 (2026-10-31)

플레이어와 편집기의 보기·되돌리기 기능을 보강했다. 킹플레이어·킹컷·킹뷰 공식 페이지는 이 빌드 시점에 접근하지 못했다. 따라서 이번 기능은 검색으로 확인한 소개 내용과 앱의 공백을 기준으로 했으며, 공식 기능 목록과의 대조는 하지 않았다.

### 추가된 것

- **라이브러리 영상 보기 도구**: A·B 지점으로 구간 반복, 재생 속도 0.5~2배, 보기 회전(90° 단위)과 좌우·상하 반전. 회전과 반전은 화면 표시에만 적용되며 파일을 바꾸지 않는다. 회전 중에는 재생 막대도 함께 돌아간다.
- **라이브러리 이미지 확대**: 휠로 커서 위치를 기준으로 1~8배 확대, 확대 상태에서 끌어서 이동, 더블클릭으로 맞춤.
- **영상 편집기 실행 취소·다시 실행**: 버튼과 Ctrl+Z, Ctrl+Y(Ctrl+Shift+Z). 같은 클립의 슬라이더 조절은 한 단계로 묶고, 추가·분할·삭제는 각각 한 단계다. 최대 100단계.

### 제한

- 공식 킹플레이어·킹컷·킹뷰의 기능 목록과 대조하지 않았다. 다른 기능이 빠져 있을 수 있다.
- 자막 표시, 재생목록, 즐겨찾기, 이미지 목록 키보드 이동은 이번 빌드에 없다.

## 1.4.0 (2026-10-29)

영상 편집기(타임라인)와 라이브러리 미리보기 크기 조절을 추가했다.

### 추가된 것

- **라이브러리 미리보기 크기 스위치**: 상세 패널 머리에 작게·보통·크게·최대 스위치, 그리드와 패널 사이의 드래그 핸들. '최대'는 그리드를 숨기고 전체 폭을 쓴다. 값은 기억된다.
- **영상 편집 탭** (프로젝트는 앱 DB 에 자동 저장)
  - 클립: 여러 파일 이어 붙이기, 구간(시작·끝, 재생 헤드로 지정), 재생 헤드에서 분할, 순서 바꾸기, 복제, 제거
  - 속도 0.25~4배 (음성도 음높이를 유지한 채 같이 조정), 볼륨, 음소거
  - 90° 회전, 좌우·상하 뒤집기, 밝기·대비·채도, 선명하게, 노이즈 제거
  - **손떨림 보정** (vidstab 2-pass, 클립별)
  - **전환** 9종 (페이드·디졸브·닦기·밀기·원·검정 페이드, xfade + acrossfade), 길이 조절
  - **텍스트 오버레이** (클립별 여러 개, 위치·크기·색·배경 상자·표시 구간)
  - **배경 음악** (볼륨, 페이드 인/아웃, 반복, 원본 음성 비율)
  - **워터마크 이미지** (위치·크기·불투명도)
  - 캔버스 프리셋 (자동, 1080p, 720p, 4K, 세로, 정사각형), 프레임레이트, 출력 컨테이너·코덱·CRF·프리셋
  - **미리보기 렌더** (640px 저화질, 앱 안에서 재생)과 **내보내기** (새 파일, 번호 붙임). 진행률·남은 시간·취소. 내보내기 결과는 ffprobe 로 길이·해상도·트랙을 검증한 뒤 확정하고, 등록된 라이브러리 폴더면 바로 인덱싱된다
- 가운데 미리보기는 재생 헤드 시점의 **원본 프레임**(효과 미적용)이며 화면에 그렇게 표시한다. 효과가 적용된 결과는 미리보기 렌더나 내보내기로 본다.
- **새 앱 아이콘**: 필름 프레임 + 재생 삼각형 + 압축 화살표 배지 (`scripts/gen-icon.py` 로 재현, PNG 512 와 다중 크기 ICO)

### 제한 (CapCut 과 다른 점)

- 실시간 효과 미리보기, 키프레임 애니메이션, 다중 영상 트랙(PiP), 마스크, 자동 자막(음성 인식), 템플릿·스티커·효과 라이브러리, AI 기능은 없다.
- 텍스트는 글꼴 하나(Windows: 맑은 고딕, 없으면 시스템 기본), 애니메이션 없음. 전환은 FFmpeg xfade 종류에 한정된다.
- 손떨림 보정은 렌더 시간이 크게 늘어난다. 캔버스 맞춤은 레터박스(검정)뿐이며 자동 크롭은 없다.
- 미리보기 렌더는 전체를 다시 렌더링하므로 긴 프로젝트에서는 시간이 걸린다.

  - 실행 취소·다시 실행·원본으로
  - 미리보기는 메인 프로세스가 저장과 같은 필터 체인으로 만든 축소본이다 (화면에서 그린 근사치가 아님)
  - 저장: 원본과 같은 형식 / JPEG / PNG / WebP(FFmpeg 에 libwebp 가 있을 때), 품질, 같은 폴더에 접미사 저장 또는 다른 이름으로 저장. 결과는 ffprobe 로 해상도를 검증한 뒤 확정한다. 등록된 라이브러리 폴더 안이면 바로 인덱싱된다.
- **화면 캡처**: 화면·창 목록에서 골라 PNG 로 사진 폴더의 "VideoSlim 캡처"에 저장하고 편집기에 연다. 지연(3/5/10초), 캡처 전 앱 창 최소화 옵션.

### 안전 규칙

- 원본 이미지는 읽기만 한다. 저장은 항상 새 파일이며 이름이 겹치면 " (2)" 번호를 붙인다. "다른 이름으로 저장"에서 기존 파일을 골라도 덮어쓰지 않는다.
- 캡처 파일도 기존 파일을 덮어쓰지 않는다. 네트워크 전송은 없다.

### 제한

- EXIF 등 메타데이터는 결과에 보존되지 않는다 (FFmpeg 이미지 출력의 한계). JPEG 로 저장하면 알파 채널이 사라진다 (화면에 알림).
- 레이어, 브러시, 텍스트, 선택 영역 보정, 배치 처리, AI 업스케일·복원은 없다.
- HEIC/RAW 는 열 수 없다. 애니메이션 GIF/WebP 는 첫 프레임만 편집된다.
- 화면 캡처는 운영체제가 허용하는 범위에서만 동작한다. Windows 에서 보호된 콘텐츠(DRM)는 검게 나온다.

## 1.2.0 (2026-10-27)

외부 자막 파일 자동 감지와 결과 포함을 추가했다.

### 추가된 것

- **외부 자막 감지**: 분석 시 영상과 같은 폴더에서 `영상.srt`, `영상.ko.srt`, `영상.ko.forced.ass` 형태의 `.srt/.ass/.ssa/.vtt` 파일을 찾는다 (최대 10개, 20 MiB 이하). 형식은 ffprobe 로 확인하고, 문자 인코딩은 UTF-8(BOM 유무)·UTF-16·CP949 를 판정한다. 파일명 태그에서 언어 코드를 붙인다 (ko→kor 등).
- **결과 포함**: MKV 출력에는 SRT·ASS 를 복사하고 WebVTT 는 SRT 로 변환한다. MP4 출력에는 mov_text 로 변환한다 (ASS 스타일은 사라지며 화면에 알린다). 원본 유지 모드에서도 합쳐진다. 결과 검증의 자막 트랙 수에 포함된다.
- **안전 규칙**: 자막 원본은 읽기만 한다. CP949·UTF-16 변환은 작업 임시 폴더의 복사본에만 한다. 분석 뒤 자막 파일이 바뀌면 `INPUT_CHANGED` 로 중단한다. 읽을 수 없는 자막은 사유와 함께 제외하고 영상 처리는 계속한다.
- 작업 상세의 "외부 자막 파일" 목록과 "같은 이름의 외부 자막 파일을 결과에 포함" 체크, 설정의 새 작업 기본값.

### 제한

- 라이브러리 미리보기 재생에는 자막을 표시하지 않는다. 자막 굽기(하드섭), 편집, 싱크 조정은 없다.
- 이미지 자막 파일(.sub/.idx)은 대상이 아니다.
- 설정 미리보기(비교 탭)와 샘플 추천 인코딩에는 외부 자막을 넣지 않는다.

## 1.1.0 (2026-10-27)

미디어 라이브러리와 재생 미리보기를 추가했다 (`docs/PLAN_MEDIA_LIBRARY.md` L1~L5).

### 추가된 것

- **라이브러리 탭**: 폴더 등록(하위 폴더 포함), 백그라운드 인덱싱(진행률·취소), 폴더 트리, 썸네일 그리드/리스트(가상 스크롤), 상세 패널
- **썸네일과 스크럽**: 영상·이미지 썸네일, 영상 썸네일 위에서 마우스 위치에 따른 시점 미리보기
- **재생 미리보기**: 직접 재생(H.264·VP8·VP9·AV1) → 프레임 보기 → 미리보기 변환본(H.264, "변환본" 표시) 순서의 폴백
- **관리**: 평점·색상 라벨·태그·메모(앱 DB 저장, 파일은 수정하지 않음), 필터·정렬·검색, 선택 항목 압축 대기열 추가, 압축 연결 표시, 중복 후보(크기·길이)와 SHA-256 확정
- **비교 탭 완성**: 완료 작업의 원본·결과를 같은 시점 프레임으로 나란히·전환·와이프 비교, 1/2/4배 확대, 동기 스크롤, 동기 재생
- **설정 미리보기**: 준비된 작업의 현재 설정으로 1~60초 구간을 실제 인코딩해 원본과 비교 (작업 결과로 저장하지 않음)
- 설정: 썸네일 캐시 상한, 캐시 비우기
- 전용 미디어 프로토콜(`vslim-media://`): 토큰 기반, Range 지원, 경로 비노출

### 제한

- HEIC/HEIF·RAW 이미지는 목록에 나타나지 않는다 (번들 FFmpeg·Chromium 모두 디코딩 불가)
- JPEG 의 EXIF 회전은 썸네일에 반영되지 않는다
- 파일 이동·삭제·이름 바꾸기, EXIF/XMP 편집, 폴더 감시는 제공하지 않는다
- 1만 개 이상 폴더의 인덱싱 시간은 실측하지 않았다

## 1.0.0 (2026-10-21)

첫 배포 후보 빌드입니다. 사용자 승인 없이 외부에 게시하지 않습니다.

### 포함된 것

- 영상 분석(ffprobe)과 지원·제한·차단 판정, 트랙별 처리 정책 표시
- 압축 모드: 원본 유지, 고품질 자동(기본), 빠른 압축, 목표 용량(2-pass, 재시도 최대 3회)
- 샘플 구간 SSIM 기반 CRF 추천 (샘플 평가임을 명시, VMAF 미사용)
- 작업 큐(동시 1개), 순서 변경, 취소, 재시도, 일시정지, 재실행 시 중단 복구
- 결과 검증 후 확정 저장, 결과가 더 크면 `no_savings` 로 표시하고 원본 유지
- 하드웨어 인코더(NVENC·QSV·AMF) 탐지와 테스트 인코딩, 실패 시 CPU 대체
- Windows 번들 FFmpeg 6.0 (gyan.dev essentials, GPL v3)
- 한국어 UI, 밝은·어두운 테마, 로그 내보내기(경로 마스킹)

### 알려진 제한

- 설치 파일은 **서명되지 않았습니다**. Windows SmartScreen 경고가 나옵니다.
- 하드웨어 인코더는 실제 장치에서 검증하지 않았습니다. 실패하면 CPU 로 대체하고 결과에 기록합니다.
- 원본·결과 비교 화면은 아직 없습니다.
- HDR·Dolby Vision·인터레이스·알파 채널 영상은 재인코딩을 차단합니다 (원본 유지 모드만 가능).
- 샘플 추천의 SSIM 기준 0.97 은 초기 실험값입니다.
- 번들 FFmpeg 는 GPL v3 입니다. 배포자는 대응 소스 제공 의무를 이행해야 합니다 (`docs/RELEASE_CHECKLIST.md` 2절).

### 이 빌드에서 고친 결함 (코드 리뷰)

- 앱 시작 직후 도구 탐지가 끝나기 전에 등록한 작업이 `TOOL_NOT_FOUND` 로 실패하던 경합
- 재시도 후 재분석한 파일 상태를 변경 감지 기준에 반영하지 않아 `INPUT_CHANGED` 가 잘못 나던 문제
- 처리 시간 추정이 원본 유지 모드의 속도와 섞이던 문제 (모드별로 분리)
- 검증 단계(디코딩 검사, 패킷 수 계수)가 취소 신호를 받지 않던 문제
- 샘플 추천 계산 중 설정 변경·삭제·시작이 허용되던 경합
- 하드웨어 인코더에 10비트 `yuv420p10le` 를 넘기던 문제 (`p010le` 로 변경)
- 샘플 측정에서 MP4 후보가 CFR 로 바뀌어 기준본과 프레임이 어긋날 수 있던 문제 (`-fps_mode passthrough`)
- 창이 임의의 `file://` 주소로 탐색할 수 있던 문제 (앱 렌더러 주소만 허용)
- 확정 링크 후 임시 이름 삭제 실패를 치명 오류로 다루던 문제
- 초기 조회 전에 도착한 작업 변경 이벤트를 놓치던 문제
