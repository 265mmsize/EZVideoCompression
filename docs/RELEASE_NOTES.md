# 릴리스 노트

## 1.3.0 (2026-10-29)

이미지 편집기와 화면 캡처를 추가했다.

### 추가된 것

- **이미지 편집 탭**: 라이브러리의 이미지 상세 "이미지 편집" 또는 탭의 "이미지 열기"로 연다.
  - 자르기(드래그 또는 숫자 입력, 비율 프리셋), 90° 회전, 좌우·상하 뒤집기, 미세 회전(-45~45°, 빈 영역 색 지정)
  - 크기 조정(프리셋·비율 유지·Lanczos/Bicubic)
  - 화질 보정: 선명하게(unsharp), 노이즈 제거(hqdn3d), 밝기·대비·채도·감마(eq), 자동 레벨(normalize). **모두 FFmpeg 필터이며 AI 복원이 아니다.** 확대도 보간일 뿐 없는 세부 정보는 생기지 않는다.
  - 실행 취소·다시 실행·원본으로
  - 미리보기는 메인 프로세스가 저장과 같은 필터 체인으로 만든 축소본이다 (화면에서 그린 근사치가 아님)
  - 저장: 원본과 같은 형식 / JPEG / PNG / WebP(FFmpeg 에 libwebp 가 있을 때), 품질, 같은 폴더에 접미사 저장 또는 다른 이름으로 저장. 결과는 ffprobe 로 해상도를 검증한 뒤 확정한다. 등록된 라이브러리 폴더 안이면 바로 인덱싱된다.
- **화면 캡처**: 화면·창 목록에서 골라 PNG 로 사진 폴더의 "VideoSlim 캡처"에 저장하고 편집기에 연다. 지연(3/5/10초), 캡처 전 앱 창 최소화 옵션.

### 안전 규칙

- 원본 이미지는 읽기만 한다. 저장은 항상 새 파일이며 이름이 겹치면 " (2)" 번호를 붙인다. "다른 이름으로 저장"에서 기존 파일을 골라도 덮어쓰지 않는다.
- 캡처 파일도 기존 파일을 덮어쓰지 않는다. 네트워크 전송은 없다.

### 제한

- EXIF 등 메타데이터는 결과에 보존되지 않는다 (FFmpeg 이미지 출력의 한계). JPEG 로 저장하면 알파 채널이 사라진다 (화면에 알림).
- 레이어, 브러시, 텍스트, 선택 영역 보정, 배치 처리, AI 업스케일·복원은 없다.
- HEIC/RAW 는 열 수 없다. 애니메이션 GIF/WebP 는 첫 프레임만 편집된다.
- 화면 캡처는 운영체제가 허용하는 범위에서만 동작한다. Windows 에서 보호된 콘텐츠(DRM)는 검게 나온다.

## 1.2.0 (2026-10-27)

외부 자막 파일 자동 감지와 결과 포함을 추가했다.

### 추가된 것

- **외부 자막 감지**: 분석 시 영상과 같은 폴더에서 `영상.srt`, `영상.ko.srt`, `영상.ko.forced.ass` 형태의 `.srt/.ass/.ssa/.vtt` 파일을 찾는다 (최대 10개, 20 MiB 이하). 형식은 ffprobe 로 확인하고, 문자 인코딩은 UTF-8(BOM 유무)·UTF-16·CP949 를 판정한다. 파일명 태그에서 언어 코드를 붙인다 (ko→kor 등).
- **결과 포함**: MKV 출력에는 SRT·ASS 를 복사하고 WebVTT 는 SRT 로 변환한다. MP4 출력에는 mov_text 로 변환한다 (ASS 스타일은 사라지며 화면에 알린다). 원본 유지 모드에서도 합쳐진다. 결과 검증의 자막 트랙 수에 포함된다.
- **안전 규칙**: 자막 원본은 읽기만 한다. CP949·UTF-16 변환은 작업 임시 폴더의 복사본에만 한다. 분석 뒤 자막 파일이 바뀌면 `INPUT_CHANGED` 로 중단한다. 읽을 수 없는 자막은 사유와 함께 제외하고 영상 처리는 계속한다.
- 작업 상세의 "외부 자막 파일" 목록과 "같은 이름의 외부 자막 파일을 결과에 포함" 체크, 설정의 새 작업 기본값.

### 제한

- 라이브러리 미리보기 재생에는 자막을 표시하지 않는다. 자막 굽기(하드섭), 편집, 싱크 조정은 없다.
- 이미지 자막 파일(.sub/.idx)은 대상이 아니다.
- 설정 미리보기(비교 탭)와 샘플 추천 인코딩에는 외부 자막을 넣지 않는다.

## 1.1.0 (2026-10-27)

미디어 라이브러리와 재생 미리보기를 추가했다 (`docs/PLAN_MEDIA_LIBRARY.md` L1~L5).

### 추가된 것

- **라이브러리 탭**: 폴더 등록(하위 폴더 포함), 백그라운드 인덱싱(진행률·취소), 폴더 트리, 썸네일 그리드/리스트(가상 스크롤), 상세 패널
- **썸네일과 스크럽**: 영상·이미지 썸네일, 영상 썸네일 위에서 마우스 위치에 따른 시점 미리보기
- **재생 미리보기**: 직접 재생(H.264·VP8·VP9·AV1) → 프레임 보기 → 미리보기 변환본(H.264, "변환본" 표시) 순서의 폴백
- **관리**: 평점·색상 라벨·태그·메모(앱 DB 저장, 파일은 수정하지 않음), 필터·정렬·검색, 선택 항목 압축 대기열 추가, 압축 연결 표시, 중복 후보(크기·길이)와 SHA-256 확정
- **비교 탭 완성**: 완료 작업의 원본·결과를 같은 시점 프레임으로 나란히·전환·와이프 비교, 1/2/4배 확대, 동기 스크롤, 동기 재생
- **설정 미리보기**: 준비된 작업의 현재 설정으로 1~60초 구간을 실제 인코딩해 원본과 비교 (작업 결과로 저장하지 않음)
- 설정: 썸네일 캐시 상한, 캐시 비우기
- 전용 미디어 프로토콜(`vslim-media://`): 토큰 기반, Range 지원, 경로 비노출

### 제한

- HEIC/HEIF·RAW 이미지는 목록에 나타나지 않는다 (번들 FFmpeg·Chromium 모두 디코딩 불가)
- JPEG 의 EXIF 회전은 썸네일에 반영되지 않는다
- 파일 이동·삭제·이름 바꾸기, EXIF/XMP 편집, 폴더 감시는 제공하지 않는다
- 1만 개 이상 폴더의 인덱싱 시간은 실측하지 않았다

## 1.0.0 (2026-10-21)

첫 배포 후보 빌드입니다. 사용자 승인 없이 외부에 게시하지 않습니다.

### 포함된 것

- 영상 분석(ffprobe)과 지원·제한·차단 판정, 트랙별 처리 정책 표시
- 압축 모드: 원본 유지, 고품질 자동(기본), 빠른 압축, 목표 용량(2-pass, 재시도 최대 3회)
- 샘플 구간 SSIM 기반 CRF 추천 (샘플 평가임을 명시, VMAF 미사용)
- 작업 큐(동시 1개), 순서 변경, 취소, 재시도, 일시정지, 재실행 시 중단 복구
- 결과 검증 후 확정 저장, 결과가 더 크면 `no_savings` 로 표시하고 원본 유지
- 하드웨어 인코더(NVENC·QSV·AMF) 탐지와 테스트 인코딩, 실패 시 CPU 대체
- Windows 번들 FFmpeg 6.0 (gyan.dev essentials, GPL v3)
- 한국어 UI, 밝은·어두운 테마, 로그 내보내기(경로 마스킹)

### 알려진 제한

- 설치 파일은 **서명되지 않았습니다**. Windows SmartScreen 경고가 나옵니다.
- 하드웨어 인코더는 실제 장치에서 검증하지 않았습니다. 실패하면 CPU 로 대체하고 결과에 기록합니다.
- 원본·결과 비교 화면은 아직 없습니다.
- HDR·Dolby Vision·인터레이스·알파 채널 영상은 재인코딩을 차단합니다 (원본 유지 모드만 가능).
- 샘플 추천의 SSIM 기준 0.97 은 초기 실험값입니다.
- 번들 FFmpeg 는 GPL v3 입니다. 배포자는 대응 소스 제공 의무를 이행해야 합니다 (`docs/RELEASE_CHECKLIST.md` 2절).

### 이 빌드에서 고친 결함 (코드 리뷰)

- 앱 시작 직후 도구 탐지가 끝나기 전에 등록한 작업이 `TOOL_NOT_FOUND` 로 실패하던 경합
- 재시도 후 재분석한 파일 상태를 변경 감지 기준에 반영하지 않아 `INPUT_CHANGED` 가 잘못 나던 문제
- 처리 시간 추정이 원본 유지 모드의 속도와 섞이던 문제 (모드별로 분리)
- 검증 단계(디코딩 검사, 패킷 수 계수)가 취소 신호를 받지 않던 문제
- 샘플 추천 계산 중 설정 변경·삭제·시작이 허용되던 경합
- 하드웨어 인코더에 10비트 `yuv420p10le` 를 넘기던 문제 (`p010le` 로 변경)
- 샘플 측정에서 MP4 후보가 CFR 로 바뀌어 기준본과 프레임이 어긋날 수 있던 문제 (`-fps_mode passthrough`)
- 창이 임의의 `file://` 주소로 탐색할 수 있던 문제 (앱 렌더러 주소만 허용)
- 확정 링크 후 임시 이름 삭제 실패를 치명 오류로 다루던 문제
- 초기 조회 전에 도착한 작업 변경 이벤트를 놓치던 문제
