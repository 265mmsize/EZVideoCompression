# 지원 형식과 제한 사항

이 문서는 현재 빌드의 실제 동작을 기준으로 한다. 아직 검증하지 않은 항목은 "미검증"으로 표시한다.

## 1. 입력 컨테이너

확장자로 판단하지 않는다. ffprobe 가 읽은 결과로 판단한다. 아래 목록은 **폴더 추가 시 후보로 삼는 확장자**다.
파일을 직접 고른 경우에는 확장자와 무관하게 ffprobe 가 판정한다.

| 확장자                                               | 상태           | 비고                                                               |
| ---------------------------------------------------- | -------------- | ------------------------------------------------------------------ |
| MP4 / M4V / MOV                                      | 지원           | 테스트: H.264 SDR, 회전 메타데이터                                 |
| MKV                                                  | 지원           | 테스트: 다중 음성, 자막, 10비트 H.265                              |
| AVI / WebM                                           | 후보 등록 가능 | ffprobe 가 읽으면 분석하지만, 실제 파일로 검증하지 않았다 (미검증) |
| WMV / FLV / MPG / MPEG / TS / MTS / M2TS / 3GP / OGV | 후보 등록 가능 | 미검증                                                             |
| 손상된 파일                                          | 실패 표시      | 테스트: 임의 바이트 파일 → `PROBE_FAILED`, 앱은 계속 동작          |

## 2. 출력

| 항목                                     | 상태                        |
| ---------------------------------------- | --------------------------- |
| MP4                                      | 지원                        |
| MKV                                      | 지원                        |
| H.264 (libx264)                          | 지원                        |
| H.265 (libx265, MP4 는 hvc1 태그)        | 지원                        |
| H.264 / H.265 하드웨어 (NVENC, QSV, AMF) | 구현됨, **장치에서 미검증** |
| AV1                                      | 미구현                      |
| HDR 보존 출력                            | 미구현 (차단)               |
| WebM 출력                                | 미구현                      |

## 3. 특수 입력 처리

| 입력 특성                            | 원본 유지                            | 재인코딩                     | 근거                                                                                                          |
| ------------------------------------ | ------------------------------------ | ---------------------------- | ------------------------------------------------------------------------------------------------------------- |
| HDR (PQ / HLG)                       | 경고 후 복사                         | 차단                         | 검증된 HDR 경로가 없다                                                                                        |
| Dolby Vision                         | 경고 후 복사                         | 차단                         | 검증된 경로가 없다                                                                                            |
| 알파 채널                            | 경고                                 | 차단                         | H.264/H.265 로 안전하게 바꿀 수 없다                                                                          |
| 인터레이스                           | 경고 후 복사                         | 차단                         | 디인터레이스 미검증                                                                                           |
| 10비트 (H.264 출력)                  | 경고                                 | 차단                         | 조용한 8비트 변환 금지                                                                                        |
| 10비트 (H.265 출력)                  | 복사                                 | 10비트 유지                  |                                                                                                               |
| 이미지 자막 (PGS, VobSub)            | MKV 복사 / MP4 제외                  | 같은 규칙                    | MP4 에 넣을 수 없다                                                                                           |
| 외부 자막 파일 (.srt/.ass/.ssa/.vtt) | 결과에 합침 (MKV 복사, MP4 mov_text) | 같은 규칙                    | 1.2.0. 같은 폴더의 `영상.srt`, `영상.ko.srt` 형식만. UTF-8·UTF-16·CP949 자동 판정. 테스트: UTF-8 + CP949 자막 |
| 첨부 폰트                            | MKV 복사 / MP4 제외                  | 같은 규칙                    | MP4 미지원                                                                                                    |
| 다중 음성                            | 모두 유지                            | 모두 유지 (호환 안 되면 AAC) | 테스트: 한국어·영어 2트랙                                                                                     |
| 다중 영상 / 커버 이미지              | 제외 (정보 표시)                     | 제외                         | 주 영상 하나만 처리                                                                                           |
| 회전 메타데이터                      | 유지                                 | 픽셀 회전 후 재인코딩        | 테스트: display matrix 90°                                                                                    |
| VFR (타임스탬프 불규칙)              | 복사                                 | passthrough 재인코딩         | 테스트: 프레임 일부 제거 픽스처. 타임스탬프 기반 판정은 미구현                                                |
| 오디오 없는 영상                     | 정상                                 | 정상                         | 테스트 있음                                                                                                   |
| 길이를 모르는 파일                   | 복사 가능                            | 불확정 진행률                | 목표 용량 모드는 차단                                                                                         |
| 한글·공백 경로                       | 지원                                 | 지원                         | 테스트: `한글 경로 폴더/테스트 영상 (1).mp4`                                                                  |
| 네트워크 드라이브                    | 미검증                               | 미검증                       | 분석 시간 초과(60초)는 `PROBE_TIMEOUT`                                                                        |

## 6. 알려진 제한

- 하드웨어 인코더는 이 개발 환경의 GPU 부재로 실제 장치에서 실행하지 않았다.
- 샘플 추천의 구간은 고정 위치다. 장면 전환이 적은 영상에서는 대표성이 떨어질 수 있다.
- 샘플 추천의 SSIM 기준 0.97 은 초기 실험값이다.
- Windows 빌드에는 FFmpeg 6.0 (gyan.dev essentials, GPL v3) 이 번들된다. 설정에서 다른 경로를 지정할 수 있다.
- 번들 FFmpeg 6.0 은 libvmaf 를 포함하지만, 이 앱은 아직 VMAF 를 사용하지 않는다.
- 설치 프로그램은 서명되지 않았다.

## 8. 이미지 편집 · 화면 캡처 (1.3.0)

| 항목            | 상태                                                                                                                                |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 열 수 있는 형식 | FFmpeg 가 읽는 정지 이미지 (JPEG, PNG, WebP, GIF, BMP, TIFF, AVIF). TIFF 등 브라우저가 못 읽는 형식은 표시용 JPEG 변환본을 보여준다 |
| 저장 형식       | JPEG(품질 1~100, 90 이상 4:4:4), PNG(알파 유지), WebP(libwebp 있을 때). '원본과 같게'는 JPEG→JPEG, WebP→WebP, 나머지→PNG            |
| 기본 편집       | 자르기(원본 픽셀 좌표), 90° 회전, 좌우·상하 뒤집기, 미세 회전(-45~45°, 캔버스 확장·채움색), 크기 조정(Lanczos/Bicubic)              |
| 화질 보정       | unsharp, hqdn3d, eq(밝기·대비·채도·감마), normalize(자동 레벨). **AI 아님**. 확대는 보간만                                          |
| 검증            | 저장 결과를 ffprobe 로 다시 읽어 계산한 해상도와 같은지 확인한 뒤 확정                                                              |
| 메타데이터      | EXIF·XMP·ICC 는 보존되지 않음 (알림 표시)                                                                                           |
| 화면 캡처       | 화면·창 선택, PNG, 지연, 앱 창 최소화. 사진 폴더의 "VideoSlim 캡처"에 저장. Linux xvfb 에서 E2E 확인, Windows 실기기는 미검증       |
| 미구현          | 레이어·브러시·텍스트·부분 선택, 배치 처리, AI 업스케일·복원, 애니메이션 편집, HEIC/RAW                                              |

## 7. 미디어 라이브러리 (1.1.0)

| 항목                                      | 상태                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 폴더 등록·하위 폴더·다시 인덱싱·등록 해제 | 구현 (파일은 건드리지 않음)                                                                                          |
| 인덱싱 대상                               | 영상: 작업 목록과 같은 확장자. 이미지: JPEG, PNG, GIF, WebP, BMP, TIFF, AVIF                                         |
| HEIC/HEIF, RAW                            | **미지원** (번들 FFmpeg·Chromium 모두 디코딩 불가). 목록에 나타나지 않음                                             |
| 썸네일                                    | 영상 10% 지점 프레임, 이미지 축소본 (JPEG 320px). 회전 메타데이터는 영상에만 적용되며 JPEG EXIF 회전은 반영하지 않음 |
| 썸네일 위 스크럽                          | 영상 길이에 따라 최대 10개 시점                                                                                      |
| 직접 재생                                 | H.264·VP8·VP9·AV1 + MP4/MOV/WebM. HEVC·MKV 는 프레임 보기 또는 변환본                                                |
| 음성                                      | AAC·MP3·Opus·Vorbis·FLAC·PCM 재생. AC-3·DTS 는 소리 없이 재생 (표시)                                                 |
| 이미지 표시                               | JPEG·PNG·GIF·WebP·BMP·AVIF 직접, TIFF 는 변환 JPEG                                                                   |
| 미리보기 변환본                           | H.264 ≤1280px ≤10분 CRF 28, 취소 가능, "변환본" 표시                                                                 |
| 설정 미리보기                             | 준비됨 작업의 현재 설정으로 1~60초 구간 실제 인코딩 (원본 유지 모드 제외)                                            |
| 비교                                      | 프레임 나란히·전환·와이프, 1/2/4배 확대, 동기 스크롤, 양쪽 직접 재생 시 동기 재생                                    |

| 필터·정렬                                 | 종류, 폴더, 검색, 평점, 라벨, 태그, 압축 여부, 없어진 파일 포함 / 이름·날짜·크기·길이·평점                           |
