## 미구현 목록 (정리)

1. 원본·결과 비교 화면 (프레임 동기화, 확대, 샘플 지표 표시)
2. 움직임 기반 샘플 구간 선택
3. 타임스탬프 기반 VFR 판정 (`ffprobe -show_packets` 기반)
4. 전체 프레임 디코딩 검증과 전체 영상 품질 평가
5. 작업별 결과 보관 선택 (현재는 전역 설정)
6. 하드웨어 인코더의 장치별 실측 검증
7. HDR 보존, Dolby Vision, 인터레이스 처리, 알파 채널 출력, AV1
8. 폴더 감시, 예약 처리
9. macOS 빌드 검증, 서명, 공증
10. FFmpeg 번들과 라이선스 이행 절차 확정
11. Windows 설치·실행 검증
12. 자동 E2E 의 드래그앤드롭, 폴더 추가 시나리오
